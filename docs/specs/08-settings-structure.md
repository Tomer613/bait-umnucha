# 08 · מבנה מסך ההגדרות

סטטוס: מיושם (2026-10-15). ניווט: תפריט צד מקובץ. שמירה: מיידית בכל מקום.

## המצב היום

8 לשוניות אופקיות. בעיות:

1. **לשוניות שמערבבות נושאים.**
   - "פרטי החברה ומכתבים" מכילה: פורמט תאריך עברי, פתיח וחתימה למודעות, דמי ועד ברירת מחדל לבניין חדש, ספי התראות למסך המשימות, פרטי החברה וטלפונים.
   - "קטגוריות וקליטת קבצים" מכילה: קטגוריות הוצאה, כללי סיווג, שמות הפקדת חיובית, שמות העברות למנהל, זיהוי גביות מיוחדות.
2. **הגדרות מודעות מפוצלות.** פורמט תאריך, פתיח וחתימה נמצאים ב"פרטי החברה ומכתבים". התבניות נמצאות ב"תבניות מודעות".
3. **שני מנגנוני שמירה.** "פרטי החברה ומכתבים" שומרת רק בלחיצה על כפתור בתחתית העמוד. כל שאר הלשוניות שומרות מיד. קל לאבד שינויים.
4. **שני סגנונות עיצוב.** "פרטי החברה ומכתבים" וגיבוי בנויים בעיצוב ישן (כותרות, מסגרות וריווח אחרים). שאר הלשוניות בנויות בכרטיס האחיד.

## ההצעה

### חלוקה לפי תחום, בקבוצות

| קבוצה | עמוד | מה בו |
|---|---|---|
| ארגון | בניינים | רשימת הבניינים + ברירות מחדל לבניין חדש (דמי ועד) |
| ארגון | פרטי החברה | שם, מנהל, טלפונים, מיילים, שורת יצירת קשר |
| כספים | קטגוריות הוצאה | קטגוריות + כללי סיווג אוטומטי (קשורים: מחיקת קטגוריה מוחקת כללים) |
| כספים | קליטת עו״ש וחיובית | שמות הפקדת חיובית, שמות העברות למנהל, זיהוי גביות מיוחדות |
| כספים | התראות | יתרה נמוכה, חוב מתמשך |
| תקשורת | מודעות ומכתבים | פורמט תאריך, פתיח וחתימה, תבניות מודעות |
| תקשורת | פניות | קטגוריות פניות, תזכורת |
| תקשורת | דוחות | מצבי דוח שמורים |
| מערכת | תצוגה | ללא שינוי |
| מערכת | גיבוי ושחזור | ללא שינוי |

### עקביות

- רכיב כרטיס אחד לכל ההגדרות: אייקון, כותרת, שורת הסבר, תוכן.
- מנגנון שמירה אחד בכל העמודים (ראו החלטות).
- קישורים ממסכים אחרים ("שינוי בהגדרות ←") ממשיכים לעבוד ומגיעים לעמוד החדש הנכון.

## החלטות

- ניווט: תפריט צד מקובץ. בטלפון הוא הופך לרשימה נפתחת.
- שמירה: מיידית בכל מקום, עם חיווי "נשמר" ליד כותרת העמוד. חריג: עריכת פרטי בניין נשארת טופס עם שמירה וביטול, כי זו עריכת רשומה ולא הגדרה.
- כל מחיקה בהגדרות מבקשת אישור. גם שחזור מגיבוי מבקש אישור.
- מחיקת קטגוריית הוצאה מוחקת גם את כללי הסיווג שמפנים אליה. חלון האישור מפרט מה יימחק ומה יישאר.
- "שורת יצירת קשר משולבת" הוסרה מהמסך: המודעות בונות את שורת הקשר מרשימות הטלפונים והמיילים. השדה companyPhone נגזר מהן אוטומטית.
