# כללים שמסד הנתונים אוכף

**עדכון אחרון:** 17.10.2026
**מקור:** קובצי ה-migrations ב-[supabase/migrations/](../../supabase/migrations/). המסמך מתעדכן עם כל migration חדש.

## למה המסמך הזה קיים
את הכללים כאן אוכף **מסד הנתונים עצמו**. אם הקוד, משתמש או ניסיון עקיפה מנסים להפר אחד מהם, הפעולה **נדחית** ומוחזרת שגיאה. לכן:
- **אין צורך לסמוך על המסך** כדי למנוע נתונים שגויים.
- **כל כלל צריך טיפול בממשק,** כדי שהמשתמש יקבל הודעה ברורה ולא שגיאה טכנית. העמודה "טיפול בממשק" נועדה להחלטה הזו. כרגע היא ריקה, ונמלא אותה יחד בהמשך.

**מקרא לעמודה "סוג":**
- 🔒 **הרשאה:** מי רשאי לראות או לשנות.
- ✅ **תקינות:** איזה נתון מותר.
- 🔗 **קשר:** איך רשומות מתקשרות זו לזו.
- ⚙️ **אוטומטי:** משהו שמסד הנתונים עושה לבד.
