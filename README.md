# בית ומנוחה - מערכת ניהול ועד בית

מערכת אינטרנטית מודרנית וקלילה לניהול פיננסי, מעקב גבייה והוצאות, ניהול פניות (Issues), והפקת מכתבים ודוחות עבור בניינים משותפים.

## תכונות מרכזיות
- **דשבורד מרוכז לכלל הבניינים:** מעקב סטטוס דיווח, יתרות קופה וחובות פתוחים עבור 15 הבניינים המנוהלים.
- **קליטת נתונים אוטומטית:** ספיגת קובצי גבייה מחברת "חיובית" ותדפיסי עובר ושב מהבנק (CSV).
- **הזנה ידנית חכמה:** קליטת מזומן והעברות ישירות עם ציפה אוטומטית של חודשי חוב פתוחים.
- **הוצאות קבועות אוטומטיות:** שיבוץ חודשי קבוע של דמי ניהול, מפיץ ריח ושירותים נוספים.
- **גבייה מיוחדת לפרויקטים:** מעקב גבייה ייעודי עבור תקלות חריגות (תיקון צנרת / חשמל).
- **מחולל דוחות גמיש ומצבים שמורים:** הפקת דוחות הוצאות ותקבולים בפורמט PDF מעוצב ו-Excel.
- **אשף מכתבים והודעות תפוצה:** תבניות מובנות לשליחה ישירה ב-Gmail (ללא עלות) והדפסה ללוח המודעות.
- **מודול פניות (Issues):** שרשור פניות ותקלות מול נציגי הבניינים בסגנון GitHub.
- **התאמה מלאה למובייל וטאבלט:** ממשק רספונסיבי מהיר ומוכן לאריזת APK לאנדרואיד.
